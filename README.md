# Car Price Prediction using Machine Learning

## Project Overview

This project predicts car prices using Machine Learning techniques based on car features such as horsepower, engine size, car width, and car length.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

---

## Machine Learning Model

* Linear Regression

---

## Features

* Data preprocessing
* Data visualization
* Regression model training
* Price prediction
* Model evaluation

---

## Dataset

The dataset contains car-related features and corresponding prices used for training and testing the model.

---

## How to Run

1. Install required libraries
2. Open `car_price_prediction.ipynb`
3. Run all notebook cells step by step

---

## Conclusion

The project successfully predicted car prices using regression techniques and helped in understanding real-world Machine Learning applications in price prediction.
