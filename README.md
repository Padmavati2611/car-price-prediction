# Car Price Prediction using Machine Learning

## Project Overview

This project uses Machine Learning to predict the prices of cars based on various features such as horsepower, engine size, car width, car length, and other automobile-related attributes.

The project demonstrates a complete Machine Learning workflow, including data preprocessing, exploratory data analysis, visualization, model training, prediction, and evaluation.

## Objective

The main objective of this project is to build a regression model that can estimate car prices from their available features.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning Model

The project uses:

* **Linear Regression**

Linear Regression is used to model the relationship between the selected car features and the target car price.

## Project Workflow

1. Load the dataset
2. Explore the dataset
3. Perform data preprocessing
4. Analyze important car features
5. Visualize the data
6. Split the data into training and testing sets
7. Train the Linear Regression model
8. Predict car prices
9. Evaluate the model

## Features

* Exploratory Data Analysis (EDA)
* Data visualization
* Feature analysis
* Linear Regression model
* Car price prediction

## Dataset

The project uses a car price dataset containing automobile specifications and corresponding prices.

The dataset includes features related to:

## Results

The Linear Regression model is trained to predict car prices based on the available automobile features.

Model performance can be evaluated using appropriate regression metrics such as:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
